# Algorithm: Even or Odd Number Identifier

An algorithm to check whether an entered integer is even or odd:

* Step 1: Start the program.
* Step 2: Prompt the user to input an integer and store it in variable `num`.
* Step 3: Compute the remainder of the number divided by 2 (`remainder = num % 2`).
* Step 4: Check the condition:
  * If `remainder == 0`, output "The number is Even".
  * Else, output "The number is Odd".
* Step 5: End the program.
